# BuggyBoom

A rowdy kart racer in your browser: 6 tracks, circuits, time trials against your ghost, 2–4 player split-screen, and online races for up to 8 players with a 5-letter room code.

**▶ Play: https://nobluezz.github.io/buggyboom/**

Works on Mac, Windows, Linux and Chromebook in any up-to-date browser (Chrome, Edge, Firefox or Safari). Nothing to install.

## Controls
| Key | Action |
|---|---|
| W / ↑ | Gas |
| S / ↓ | Brake / reverse |
| A D / ← → | Steer |
| Space or Shift | Hop; hold while turning to drift; tap in the air for a trick |
| E / Q | Use item / use item backward |
| C | Look back |
| R | Reset if stuck |
| Esc or P | Pause |

Gamepads work too. Saves live in your browser.

Rated R: cartoon gore, crude humour, strong language (gore and swearing can each be switched off in Settings).
